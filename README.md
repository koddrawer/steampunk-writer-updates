# Steampunk Writer – kho cập nhật

App Steampunk Writer trên các máy live tự tải thư mục `app/` khi `version.json` có phiên bản mới. Không sửa tay file trong repo này nếu không chắc chắn.

- `app/` – phần cập nhật nóng (giao diện, máy 3D, logic)
- `_source/` – mã nguồn còn lại (shell, công cụ, cấu hình build)
